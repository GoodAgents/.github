**Good Agents** keeps a record of every AI agent a business runs: what it is, what it may do, what it actually did and how well it did it. It enforces each agent's role at the model and tool gateways, asks a person before sensitive actions, and gives administrators one place to onboard, review, suspend and offboard agents.

It runs on-premises as an appliance, **GA Manager**. A future **GA Director** will run many managers under one sign-in and one policy.
